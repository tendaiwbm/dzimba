<h1>About Dzimba</h1>
<p>
	Dzimba is a bot to search select Dutch housing websites for listings matching defined criteria, apply user-defined filters, and send email alerts, all in near-real time. Currently, the following platforms are scraped:
	<ol>
	    <li><a href="https://www.verra.nl/">Verra Makelaars</a></li>
	    <li><a href="https://househunting.nl/">HouseHunting</a></li>
	    <li><a href="https://www.rentanapartment.nl/">Rent An Apartment NL</a></li>
	    <li><a href="https://www.pararius.com/english">Pararius</a></li>
	    <li><a href="https://www.rentalrotterdam.nl/">Rental Rotterdam</a></li>
	    <li><a href="https://livresidential.nl/">LIV Residential</a></li>
	    <li><a href="https://woonzeker.com/">Woonzeker</a></li>
    </ol> 
</p>
